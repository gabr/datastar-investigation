# 2026.10.09

    I've typed out a half of examples from getting started guide.
    So far nothing very exciting but it's quite amazing how much
    can be done without touching JavaScript.  But definitely harder
    to trouble shoot issues as there is no way to do step by step
    debugging - you just have to look at all the signals and names
    and try to spot potential typos or miss-configuration.  In the
    end that might be a final nail in the coffin for those clever
    attribute based frameworks (angular, htmx and data-star) as just
    doing the same by hand in JavaScript is not much more work but
    way easier to trouble shoot in more complex scenarios.
